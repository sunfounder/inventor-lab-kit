Video 23: How to Set Up a PS2 Joystick
==========================================================

This lesson explains how PS2 joystick modules are read using Arduino.

* **Joystick axes:** Demonstrates reading X and Y analog values.
* **Center position:** Explains neutral and movement ranges.
* **Button input:** Shows how the joystick button is read.
* **Directional data:** Demonstrates using joystick movement values.
