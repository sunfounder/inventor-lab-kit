Video 4: LEDs steuern mit Arduino
======================================================

Diese Lektion zeigt, wie LEDs mithilfe der digitalen Ausgangspins des Arduino gesteuert werden.

* **LED-Grundlagen:** Erklärt die Polarität von LEDs und die Notwendigkeit von Vorwiderständen.
* **Verdrahtung von LEDs:** Zeigt, wie eine LED mit einem Arduino-Pin verbunden wird.
* **Digitale Ausgänge:** Demonstriert die Steuerung von LED-Zuständen per Code.
* **Einfache Sketches:** Verwendet grundlegende Sketches, um LEDs ein- und auszuschalten.
