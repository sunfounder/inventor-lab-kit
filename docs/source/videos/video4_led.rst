Video 4: LED の制御方法
======================================================

このレッスンでは、Arduino のデジタル出力ピンを使用して LED を制御する方法を実演します。

* **LED の基礎:** LED の極性と電流制限抵抗が必要な理由を説明します。
* **LED の配線:** LED を Arduino のピンに接続する方法を示します。
* **デジタル出力:** コードを使って LED の状態を制御する方法を実演します。
* **簡単なスケッチ:** 基本的なスケッチを使って LED の点灯と消灯を行います。
