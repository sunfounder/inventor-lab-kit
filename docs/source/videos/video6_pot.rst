Video 6: 可変抵抗器（ポテンショメータ）の使い方
======================================================

このレッスンでは、可変抵抗器（ポテンショメータ）を可変アナログ入力デバイスとして紹介します。

* **ポテンショメータの動作:** 抵抗値の変化が電圧にどのように影響するかを説明します。
* **アナログ入力:** Arduino でポテンショメータの値を読み取る方法を実演します。
* **配線方法:** ポテンショメータを正しく接続する方法を示します。
* **値のマッピング:** アナログ値を使って出力を制御する方法を実演します。
