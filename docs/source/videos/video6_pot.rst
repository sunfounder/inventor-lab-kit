Video 6: Verwendung von Potentiometern
======================================================

Diese Lektion führt Potentiometer als variable analoge Eingabegeräte ein.

* **Funktionsweise von Potentiometern:** Erklärt, wie sich eine Änderung des Widerstands auf die Spannung auswirkt.
* **Analoge Eingänge:** Demonstriert das Auslesen von Potentiometerwerten mit Arduino.
* **Verdrahtung:** Zeigt, wie ein Potentiometer korrekt angeschlossen wird.
* **Wertzuordnung:** Demonstriert die Nutzung analoger Werte zur Steuerung von Ausgängen.
