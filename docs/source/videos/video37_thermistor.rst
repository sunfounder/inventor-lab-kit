Video 37: Verwendung von Temperatursensoren
==========================================================

Diese Lektion führt Temperatursensoren ein und erklärt, wie deren Ausgabewerte von Arduino ausgelesen werden.

* **Temperaturmessung:** Erklärt, wie Temperatursensoren Temperaturänderungen erfassen.
* **Sensormodule:** Stellt gängige Typen von Temperatursensoren vor.
* **Datenauslesung:** Demonstriert die Umwandlung von Sensorausgaben in Temperaturwerte.
* **Signalauswertung:** Erklärt die Interpretation von Temperaturmesswerten.
