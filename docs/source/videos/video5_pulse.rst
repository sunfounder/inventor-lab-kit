Video 5: Verwendung der Pulsweitenmodulation
======================================================

Diese Lektion erklärt, wie die Pulsweitenmodulation (PWM) auf dem Arduino funktioniert.

* **PWM-Konzept:** Erklärt das Tastverhältnis und das Signal-Timing.
* **PWM-Pins:** Identifiziert die Arduino-Pins, die PWM unterstützen.
* **Analogähnliche Ausgabe:** Demonstriert die Steuerung von Ausgangspegeln mithilfe von PWM.
* **LED-Helligkeit:** Zeigt, wie PWM zur Regelung der LED-Helligkeit verwendet wird.
