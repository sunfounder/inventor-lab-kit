Video 5: How to Use Pulse Width Modulation
======================================================

This lesson explains how Pulse Width Modulation (PWM) works on the Arduino.

* **PWM concept:** Explains duty cycle and signal timing.
* **PWM pins:** Identifies Arduino pins that support PWM.
* **Analog-like output:** Demonstrates controlling output levels using PWM.
* **LED brightness:** Shows how PWM is used to vary LED brightness.
