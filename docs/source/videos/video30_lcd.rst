Video 30: Einrichtung eines LCD-Displays
==========================================================

Diese Lektion erklärt, wie Zeichen-LCD-Displays mit Arduino verwendet werden.

* **Verwendung von Bibliotheken:** Zeigt, wie LCD-Bibliotheken eingesetzt werden.
