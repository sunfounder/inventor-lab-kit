Video 30: How to Set Up an LCD Display
==========================================================

This lesson explains how character LCD displays are used with Arduino.

* **LCD types:** Introduces common character LCD modules.
* **Wiring connections:** Demonstrates connecting an LCD to Arduino.
* **Library usage:** Shows how LCD libraries are used.
* **Text output:** Demonstrates displaying characters and numbers.
