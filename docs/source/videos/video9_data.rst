Video 9: How to Use Data Types in Arduino Programs
======================================================

This lesson explains common data types used in Arduino programming.

* **Basic data types:** Introduces int, float, and boolean.
* **Memory usage:** Explains how data types affect memory consumption.
* **Value limits:** Demonstrates minimum and maximum values.
* **Type selection:** Shows how to choose appropriate data types.
