Video 31: How to Use Photoresistors
==========================================================

This lesson explains how photoresistors are used to detect light levels with Arduino.

* **Photoresistor behavior:** Explains how resistance changes with light intensity.
* **Voltage divider:** Demonstrates converting resistance changes into voltage.
* **Analog reading:** Shows how light levels are read using analog inputs.
* **Threshold detection:** Demonstrates reacting to light level changes.
