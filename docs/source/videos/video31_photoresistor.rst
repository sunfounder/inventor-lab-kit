Video 31: Verwendung von Fotowiderständen
==========================================================

Diese Lektion erklärt, wie Fotowiderstände zur Erkennung von Lichtstärken mit Arduino verwendet werden.

* **Verhalten von Fotowiderständen:** Erklärt, wie sich der Widerstand mit der Lichtintensität ändert.
* **Spannungsteiler:** Demonstriert die Umwandlung von Widerstandsänderungen in Spannung.
* **Analoge Messung:** Zeigt, wie Lichtstärken über analoge Eingänge ausgelesen werden.
* **Schwellwerterkennung:** Demonstriert das Reagieren auf Änderungen der Lichtstärke.
