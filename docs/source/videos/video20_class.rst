Video 20: Funktionsweise von Klassen und Objekten in Arduino-Programmen
===============================================================================

Diese Lektion führt grundlegende Konzepte der objektorientierten Programmierung in Arduino ein.

* **Klassen:** Erklärt, wie Klassen Daten und Verhalten definieren.
* **Objekte:** Demonstriert das Erstellen von Objekten aus Klassen.
* **Mitgliedsvariablen:** Führt Klassenattribute ein.
* **Mitgliedsfunktionen:** Zeigt, wie Klassenmethoden verwendet werden.
