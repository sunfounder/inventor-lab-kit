Video 1: Arduino 入門
======================================================

このレッスンでは、Arduino とは何か、そしてマイクロコントローラベースの電子プラットフォームとしてどのように動作するのかを説明します。

* **Arduino の概要:** Arduino とは何か、そして汎用コンピュータとどのように異なるのかを説明します。
* **マイクロコントローラの基礎:** Arduino ボード上のマイクロコントローラの役割を紹介します。
* **入力と出力:** Arduino がどのように入力を読み取り、出力を制御するかを示します。
* **プログラミングの流れ:** スケッチの作成、書き込み、実行の流れを説明します。
