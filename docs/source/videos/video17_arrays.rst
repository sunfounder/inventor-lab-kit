Video 17: Verwendung von Arrays in Arduino-Programmen
==========================================================

Diese Lektion führt Arrays ein und zeigt, wie sie zum Speichern mehrerer Werte verwendet werden.

* **Array-Konzept:** Erklärt, wie Arrays zusammengehörige Daten gruppieren.
* **Indexzugriff:** Demonstriert das Lesen und Schreiben von Array-Elementen.
* **Integration mit Schleifen:** Zeigt, wie Arrays zusammen mit Schleifen verwendet werden.
* **Speichernutzung:** Erklärt, wie Arrays im Speicher abgelegt werden.
