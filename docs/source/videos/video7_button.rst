Video 7: How to Use Push Buttons
======================================================

* **Button wiring:** Demonstrates correct wiring for button inputs.
* **Input states:** Shows how Arduino reads HIGH and LOW signals.
* **Button control:** Demonstrates triggering actions with button presses.
