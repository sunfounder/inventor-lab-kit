Video 7: Verwendung von Tastern
======================================================

Diese Lektion erklärt, wie Taster als digitale Eingänge verwendet werden.

* **Funktionsweise von Tastern:** Erklärt, wie Taster Stromkreise öffnen und schließen.
* **Verdrahtung von Tastern:** Demonstriert die korrekte Verdrahtung für Tastereingänge.
* **Eingangszustände:** Zeigt, wie Arduino HIGH- und LOW-Signale liest.
* **Tastersteuerung:** Demonstriert das Auslösen von Aktionen durch Tastendrücke.
